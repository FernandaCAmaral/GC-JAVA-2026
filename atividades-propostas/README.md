# 🎯 Atividades Propostas - Geração Caldeira 2026

Este diretório reúne as resoluções dos exercícios e desafios práticos propostos durante as aulas do programa **Geração Caldeira**, focados em **Java** e **Orientação a Objetos**.

---

## 🚀 Tecnologias Utilizadas

- **Linguagem:** Java (JDK 21)
- **IDE:** IntelliJ IDEA / VS Code
- **Versionamento:** Git & GitHub

---

## 🛠️ Como Executar os Exercícios

1. **Clone o repositório principal:**
   ```bash
   git clone git@github.com:FernandaCAmaral/GC-JAVA-2026.git
   ```
2. **Navegue até a pasta do projeto:**
   ```bash
   cd GC-JAVA-2026/atividades-propostas
   ```
3. **Abra a pasta na sua IDE de preferência e execute o arquivo Main.java correspondente ao exercício desejado.**
